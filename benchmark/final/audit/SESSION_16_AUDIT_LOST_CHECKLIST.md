### D-13. `run_graph_experiments.py` was committed but NEVER RUN end-to-end — `exp_4_5c` crashed on first invocation
- **First discovery**: 2026-05-25 session 16, when this session attempted to launch Phase 4.5 on the restarted AWS instance.
- **The bug**: `exp_4_5c` (cold-start curve) called `neo4j.run_query(...)` 3× (script lines 192, 198, 221). `Neo4jClient` has **no such method**. The actual API is `async with neo4j.session() as sess: await sess.run(...)`. The script would `AttributeError: 'Neo4jClient' object has no attribute 'run_query'` immediately on first attempt to delete cold-start nodes.
- **Why-lost evidence**: The file's mtime on the laptop is 2026-05-24 (session 14). It was committed in Stage J without ever being executed. No CI / smoke / pre-run check would have caught this — the failure is at runtime on the 1st line of `exp_4_5c`. `exp_4_5b` was OK (uses only `BenchmarkRunner.run_benchmark()`).
- **Resolution applied in session 16**: Patched the 3 calls in place — `async with neo4j.session() as sess:` + `await sess.run(...)`, wrapped in `try/finally` for `await neo4j.close()`, added `await neo4j.connect()` before the loop. Verified syntax on both laptop and instance. Launched Phase 4.5 full run after patch.
- **Suggested followup**: Add a `pytest` smoke that exercises `exp_4_5c` with N={0} (no real episodes, just verifies the API plumbing). Also flags a class of "stub scripts" — find other scripts that may have similar never-run bugs (the Stage J reorg surfaced this only because we needed to run it now).
